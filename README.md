# The Odin Project
# Javascript Course : Tic Tac Toe

As asked in the introduction of [the project](https://www.theodinproject.com/lessons/node-path-javascript-tic-tac-toe), the tic tac toe project is a tic tac toe game playable in the browser. The goal is to practice javascript and mostly object creation, probably closure, factory functions and module pattern, as those are the ones learned right before. As always, I'm going to go for the bare minimum on the project, unless I find something interesting enough to be pushed from my point of view to practice a bit more.
